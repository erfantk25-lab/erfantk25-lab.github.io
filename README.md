# Erfan Tahmasemi Portfolio

Static GitHub Pages portfolio. No build step or server is required.

## Deploy

The workflow in `.github/workflows/deploy.yml` publishes the `main` branch to GitHub Pages. In the repository settings, select **Settings → Pages → Source: GitHub Actions** once. Every push to `main` then publishes automatically.

## Local preview

Open `index.html` in a browser, or use a static server such as `npx serve .`.
